Un APK por versión publicada, más el código fuente de cada una.

|---|---|---|
| 0.2.0 | `SpotiZado-v0.2.0-debug.apk` | Rebranding a SpotiZado + icono nuevo |

en Google Play; sí para instalar y probar en un dispositivo.
